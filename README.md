# Actividad: Explorando Arreglos y Ciclos en JavaScript

Módulo 4 - Aprendizaje Esperado N°3

Este repositorio contiene la resolución práctica de la actividad AE-3 sobre arreglos, ciclos iterativos y buenas prácticas.

Evidencias de Desarrollo

1. Explorando Arreglos
Definición de un arreglo de 5 elementos, acceso al tercer elemento y manipulación con push() y pop().
1.Explorando-arreglos-en-JavaScriptr.jpg

2. Iterando sobre un Arreglo
Comparación de recorrido de elementos usando un ciclo for tradicional y el método forEach().

3. Operaciones con Arreglos
Lógica para concatenar arreglos, encontrar diferencias y filtrar números mayores a 10.

4. Aplicando Ciclos Iterativos - Parte 1
Uso de while para sumar del 1 al 10 y do/while para imprimir del 5 al 15.

5. Aplicando Ciclos Iterativos - Parte 2
Generación de tablas de multiplicar del 1 al 5 mediante ciclos for anidados.

6. Buenas Prácticas y Código Limpio
Justificación sobre la importancia de la legibilidad, indentación y nombres descriptivos en el código.
